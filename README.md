# Escuela de Guardavidas — Sumar Salud

Prototipo del sitio. Es una sola página HTML, sin dependencias ni build.

## Contenido

- `index.html` — todo el sitio (estructura, estilos y navegación)
- `img/` — las fotos. Ver `img/LEEME.txt` para los nombres exactos.

## Verlo en tu máquina

Abrí `index.html` con doble clic. Las fotos que estén en `img/` aparecen solas.

## Subirlo online

Arrastrá esta carpeta a vercel.com/new. No hace falta configurar nada:
es un sitio estático.

## Cambiar una foto

Reemplazá el archivo en `img/` conservando el nombre y volvé a subir.
